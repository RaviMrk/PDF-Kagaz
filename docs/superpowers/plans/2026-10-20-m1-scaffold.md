# Milestone 1 — Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A buildable Expo SDK 57 dev-client app with four placeholder tabs, light/dark theme, i18n, MMKV prefs, and the SQLite/Drizzle schema, with lint, format, typecheck and Jest all green.

**Architecture:** Expo Router file routes in `app/`; everything else in `src/` split by responsibility (theme, i18n, db, stores, services, utils). Preferences go through a small `KeyValueStore` interface (MMKV in the app, in-memory in tests). The DB schema is Drizzle; migrations are generated by drizzle-kit and run at startup before any screen renders.

**Tech Stack:** Expo SDK 57 (`expo@~57.0.30`, RN 0.86, New Architecture), expo-dev-client, Expo Router, TypeScript strict, Zustand, react-native-mmkv 4.x, expo-sqlite + drizzle-orm 0.45 / drizzle-kit, i18next + react-i18next + expo-localization, ESLint (eslint-config-expo) + Prettier, Jest (jest-expo) + @testing-library/react-native, better-sqlite3 (tests only).

**Spec:** `docs/REQUIREMENTS.md` (sections 4, 6, 7.1, 7.2, 8, 9 milestone 1)

## Global Constraints

- Android only; no iOS-specific code. minSdk 24, targetSdk 36, compileSdk 36.
- Dev build, NOT Expo Go (`expo-dev-client`). New Architecture (cannot be disabled).
- TypeScript `strict: true`; `npx tsc --noEmit`, `npm run lint`, `npm test` must all pass at the end of every task.
- All user-facing strings via i18next from `src/i18n/en.json`; no hard-coded UI text.
- Touch targets ≥ 48 dp; every pressable has an `accessibilityLabel`; text respects system font scaling (no `allowFontScaling={false}`).
- No `CAMERA` permission in the manifest (ML Kit scanner doesn't need it).
- Install native/Expo packages with `npx expo install <pkg>` so versions match SDK 57.
- Java for Gradle: `export JAVA_HOME=~/.gradle/jdks/eclipse_adoptium-17-aarch64-os_x.2/jdk-17.0.20.1+1/Contents/Home` (JDK 17 required; Android Studio's bundled JBR is JDK 25 and fails the RN CMake tasks); `export ANDROID_HOME=~/Library/Android/sdk`.
- Package ID (my call; open question in spec 10.4): `com.pdfkagaz.pdftoolkit`. App display name: "PDF Toolkit".
- Commit after each task; messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. Device language is Marathi or Hindi before those translations exist → UI shows English, never raw keys like `tabs.home`. (Test in Task 3.)
2. Stored theme pref is missing or garbage (e.g. `"blue"` from a bad write) → treated as `system`, no crash. (Test in Task 2.)
3. Theme set to `system` and the OS switches dark ↔ light while the app is open → colors follow without restart. (Test in Task 2.)
4. A file row is deleted from the index → its bookmarks are deleted too (requires `PRAGMA foreign_keys = ON` on every connection). (Test in Task 4.)
5. DB migration fails at startup (e.g. disk full) → a readable error screen, not a white screen or crash. (Test in Task 5.)
